# 综合态势与多源感知-预警事件无人机联动链路-设计方案

## 一、项目概述

预警事件闭环管理中，点击“联动视频”先进入光电联动页。光电设备受安装位置和可视距离限制，可能无法看清告警目标，此时需要调用无人机飞赴告警点执行直播、截图、录像与喊话等处置动作。本次将“预警事件 → 光电联动 → 无人机联动”串成完整链路，并保留原“无人机联动（已弃用）”菜单不动。

## 二、功能范围

1. 事件入口自动推荐光电设备：按告警坐标计算距离，优先选择最近且在线设备。
2. 光电联动页展示完整事件上下文：目标、规则、级别、状态、触发时间、告警坐标、当前光电距告警点距离。
3. 光电不可视提示：设备离线或距离超过 10km 时提示“建议启用无人机联动”，并在“返回事件”旁提供“无人机联动”入口。
4. 新增独立无人机联动页：展示事件上下文、告警坐标、无人机列表（状态/电量/续航/距告警点距离）、地图航线、直播画面与飞赴任务。
5. 无人机处置能力：一键飞赴告警点、悬停、返航、直播、截图、录像、喊话，所有取证与喊话记录均关联事件编号。

## 三、核心模块设计

### 事件入口

- `openLinkage(row)` 异步获取光电设备列表。
- 计算每个光电设备与告警坐标的球面距离，优先从在线设备中取最近设备；全部离线时取最近设备并在光电页提示。
- 写入联动上下文并携带 `deviceId/eventId/targetId/lat/lng/address/triggerTime` 等查询参数，保证页面刷新或返回后上下文可重建。

### 光电联动页

- 上下文条增加告警坐标、触发时间、当前光电距告警点距离。
- 设备离线或距离大于 10km 时显示黄色提示条，建议切换无人机联动。
- “返回事件”旁新增“无人机联动”按钮，携带 `opticDeviceId` 与完整事件上下文跳转 `/device/uav-linkage`。

### 无人机联动页（新路由 `/device/uav-linkage`）

- 顶部事件条：事件编号、目标、MMSI、规则、级别、状态、告警坐标、触发时间；提供“返回光电联动”和“返回事件”。
- 左侧无人机列表：名称、状态、电量、续航、距告警点距离；默认选中距告警点最近且在线设备。
- 中间地图：告警点、无人机当前位置、起降点、飞赴航线；任务执行时无人机标记沿航线推进。
- 右侧直播与控制区：Canvas 模拟机载直播画面、一键飞赴告警点、悬停、返航、截图、录像、喊话、取证与喊话记录。

## 四、数据结构与流向

`alertEvent`（告警事件）→ `opticDevice`（光电设备）→ `uavDevice`（无人机）→ `uavTask`（飞赴任务）→ `evidence/hailer`（取证与喊话记录）

- 联动上下文新增字段：`location`（告警坐标）、`triggerTime`、`fromOptics`、`opticDeviceId`。
- 无人机飞赴任务：`uavId`、`waypoints`（告警点）、`status`、`progress`、`flownDistance`、`startTime/endTime`。
- 取证记录：`deviceType: 'uav'`，携带 `eventId/targetId`；喊话记录同样携带事件上下文。

## 五、边界情况处理

1. 光电设备全部离线：仍进入光电页展示离线状态，并提示建议无人机联动。
2. 无人机电量低于 20% 或设备故障：禁止一键飞赴，列表展示原因。
3. 任务执行中：禁止重复飞赴与返航，允许截图、录像、喊话。
4. 已到达告警点：按钮状态变为“已到达”，可继续悬停、截图、录像、喊话或返航。
5. 从无人机页返回光电页：通过查询参数重建联动上下文，不依赖页面缓存。
6. 无事件上下文直达页面：以示例告警坐标兜底，页面功能仍可用。
