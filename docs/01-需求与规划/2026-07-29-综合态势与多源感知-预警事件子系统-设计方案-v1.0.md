# 预警事件子系统设计方案

## 一、项目概述

### 1.1 系统背景

综合态势与多源感知系统是面向海上态势感知与管控的综合管理平台。系统接入雷达、AIS、北斗、光电视频、频谱侦测、气象水文等多源异构数据，通过统一时空基准进行融合处理，支撑目标管控、预警事件、设备联动、AI研判、数据分析等业务场景。

### 1.2 预警事件子系统定位

预警事件是系统的中枢环节——所有感知数据最终在预警事件中被规则判定、生成告警、推动处置，然后联动设备和AI形成闭环。没有预警事件，系统就只是一个"看"的系统，有了它才变成"管"的系统。

### 1.3 核心价值

- 从被动监看向主动预警转变，降低人工盯屏工作量
- 多维度预警规则覆盖电子围栏、身份识别、行为异常三类场景
- 全生命周期事件闭环管理，处置过程可追溯、可审计
- 误报治理机制持续优化规则准确率

## 二、功能范围

### 2.1 菜单结构

```
预警事件
├── 地图区域管理           /alert/area          （单页面：左列表+右地图）
├── 预警规则管理
│   ├── 电子围栏预警       /alert/rule/fence    （表格+弹窗，关联地图区域）
│   ├── 身份识别预警       /alert/rule/blacklist（表格+批量导入）
│   └── 行为预警          /alert/rule/behavior  （卡片列表+参数配置）
└── 事件闭环管理           /alert/event          （三Tab：报警接收/报警处置/误报治理）
```

## 三、核心模块设计

### 3.1 地图区域管理

**路由**：`/alert/area`

**页面布局**：左侧区域列表（宽度280px） + 右侧 Leaflet 地图容器（flex: 1）

**左侧区域列表**：
- 搜索框 + 新增按钮
- 表格列：区域名称、类型标签（重点区域/禁入区域/巡检区域）、有效期、状态、操作（编辑/删除/绑定规则）
- 点击行高亮对应地图区域

**右侧地图**：
- Leaflet 轻量地图组件，支持卫星/矢量底图切换
- 绘制工具条：绘点、绘线、绘面（多边形）、导入边界文件（GeoJSON/KML）
- 已绘制区域半透明填充 + 边框高亮，点击弹出信息窗
- 支持拖拽编辑顶点、整体移动区域
- 区域保存后即时渲染，无需跳转其他页面验证

**新增/编辑区域弹窗**：
- 区域名称（文本输入）、区域类型（下拉：重点区域/禁入区域/巡检区域）
- 有效期（日期范围选择器）、负责人（用户选择）、备注（文本域）
- 绑定预警规则：勾选已创建的围栏规则列表 + 触发等级 + 通知方式多选

**区域变更审批**：
- 编辑区域后状态变为"待审批"，记录修改前后对比
- 审批记录表：变更内容对比（修改前/修改后）、提交人、提交时间、审批人、审批结果
- 非编辑操作（查询/查看）不受影响

### 3.2 电子围栏预警

**路由**：`/alert/rule/fence`

**页面布局**：筛选区 + 操作栏 + 表格 + 分页

**筛选区**：规则名称（输入框）、状态（下拉：全部/启用/禁用）

**操作栏**：新增规则按钮

**表格列**：
| 列名 | 说明 |
|------|------|
| 规则名称 | 文本 |
| 围栏面积 | 根据绘制多边形自动计算的 km² 面积 |
| 生效时段 | 日期范围 + 每日时间段摘要 |
| 适用目标 | 船型/吨位/来源 摘要 |
| 优先级 | 数字 |
| 告警级别 | 提示/一般/重要/紧急 颜色标签 |
| 状态 | 启用/禁用开关 |
| 操作 | 编辑/删除/查看命中历史 |

**新增/编辑弹窗**：
- 规则名称（文本输入）
- **绘制围栏区域**（核心交互）：
  - "绘制围栏区域"按钮，点击后打开**全屏绘制弹窗**（ElDialog fullscreen，盖在编辑弹窗之上）
  - 按钮下方显示面积数值（如"12.34 km²"）
  - 已绘制区域后，下方显示 200px 高的**小地图预览**（Leaflet 只读地图，自动居中适配区域）
- **全屏绘制弹窗**：
  - 工具栏：撤销（删除最后一个顶点）、清除（清空全部顶点）、实时面积显示
  - 交互提示："点击地图添加顶点，点击起点（或双击）闭合多边形"
  - Leaflet 地图占据弹窗主体，点击添加多边形顶点，已有 >=3 个顶点后点击起点附近 (<500m) 或双击地图自动闭合
  - 顶点以蓝色圆点标记，连线为蓝色虚线，已闭合面填充半透明蓝色
  - 实时计算并显示多边形面积（Shoelace 公式）
  - 底部操作栏：取消（放弃绘制，回到编辑弹窗）、保存区域（闭合多边形，关闭绘制弹窗，回到编辑弹窗同时小地图渲染多边形）
- 生效日期范围（起止日期选择器）
- 每日时间段（可添加多条，08:00-12:00 / 14:00-18:00 等）
- 按星期重复（多选：周一至周日，支持全选/工作日/周末快捷）
- 过滤条件：
  - 适用船型（多选：渔船/货船/客船/快艇/橡皮艇/三无船/全部）
  - 吨位范围（最小-最大，吨）
  - 目标来源（多选：雷达/AIS/北斗/光电/融合/全部）
- 优先级（数字输入，1最高）
- 告警级别（下拉：提示/一般/重要/紧急）

**关键交互细节**：
- 绘制弹窗打开时，若编辑已有规则，自动回显已有多边形区域
- 保存绘制后，编辑弹窗内的小地图通过 `nextTick` 延迟渲染，确保 DOM 就绪
- 编辑弹窗关闭时自动销毁小地图 Leaflet 实例，避免内存泄漏

### 3.3 身份识别预警

**路由**：`/alert/rule/blacklist`

**页面布局**：操作栏 + 表格 + 分页

**操作栏**：新增按钮、批量导入按钮、导出按钮

**搜索区**：目标名称/MMSI（输入框）、等级（下拉：全部/一般/重点/高危）、状态（下拉：全部/启用/禁用）

**表格列**：
| 列名 | 说明 |
|------|------|
| 目标名称 | 文本 |
| MMSI | 文本 |
| 呼号 | 文本 |
| 目标编号 | 文本 |
| 等级 | 一般(黄)/重点(橙)/高危(红) 标签 |
| 加入原因 | 备注摘要 |
| 命中次数 | 数字，可点击查看历史 |
| 加入时间 | 日期时间 |
| 状态 | 启用/禁用开关 |
| 操作 | 编辑/删除/查看命中历史 |

**新增弹窗**：目标名称、MMSI、呼号、目标编号、等级下拉、加入原因备注

**批量导入**：
- 上传 Excel 文件
- 自动解析字段映射（目标名称/MMSI/呼号/等级/备注）
- MMSI 去重校验，重复项高亮提示
- 导入预览表格确认后入库

**命中历史弹窗**：
- 时间线列表：命中时间、位置坐标、告警级别、处理状态
- 统计卡片：总命中次数、最近命中时间

**差异化告警策略**：
- 一般：右下角 Element Plus Notification 通知
- 重点：弹窗 + 提示音
- 高危：全屏弹窗遮罩 + 强提示音 + 地图高亮定位

### 3.4 行为预警

**路由**：`/alert/rule/behavior`

**页面布局**：船型筛选 + 新增按钮 + 规则卡片列表

**规则卡片**：每种行为规则一个卡片，包含：

**异常航速规则**：
- 适用船型多选（渔船/货船/客船/快艇/橡皮艇/三无船/全部）
- 航速上限（节）、航速下限（节）
- 持续时长（秒，过滤瞬时波动）
- 告警级别下拉
- 启用/禁用开关

**异常航向规则**：
- 适用船型多选
- 航向偏差角度阈值（度）
- 持续时长（秒）
- 告警级别下拉
- 启用/禁用开关

**异常停留规则**：
- 适用船型多选
- 停留时长阈值（分钟）
- 告警级别下拉
- 启用/禁用开关

**轨迹断线规则**：
- 适用船型多选
- 断线判定时长（秒）
- 自动研判分类：信号丢失/设备故障/目标消失/未知（多选预设）
- 告警级别下拉
- 启用/禁用开关

### 3.5 事件闭环管理

**路由**：`/alert/event`

**页面布局**：三个 Tab 切换

#### Tab 1：报警接收展示

- 顶部统计卡片：待核验数、处置中数、今日闭环数、超时未处置数
- 实时报警表格：
  | 列名 | 说明 |
  |------|------|
  | 告警等级 | 颜色标签 |
  | 规则名称 | 触发规则 |
  | 目标信息 | 目标名称/MMSI |
  | 发生时间 | 日期时间 |
  | 位置 | 坐标 |
  | 状态 | 待核验/处置中/已闭环/已归档 |
  | 操作 | 查看详情/确认有效/标记误报/联动视频 |
- 推送配置面板（右上角齿轮按钮打开抽屉）：
  - 告警级别 → 推送方式映射（弹窗/APP推送/短信/邮件）
  - 告警级别 → 推送角色映射（值班员/指挥员/设备操作员）
  - 超时阈值配置：待核验超时 X 分钟、处置中超时 Y 分钟

#### Tab 2：报警处置流程

- 表格列：与报警接收一致，增加派发对象、已耗时列
- 状态流转操作：
  ```
  待核验 → [确认有效] → 处置中 → [填写处置说明] → [闭环] → 已闭环 → [归档] → 已归档
           [标记误报] → 跳转误报治理Tab
  ```
- 派发处置：处置中状态下选择派发至具体值班人员，被派发人可见待办列表
- 操作时间线：每条事件下方展开，记录每次状态变更的操作人、时间、说明
- 超时升级：待核验/处置中超时自动升至上一告警级别，推送范围同步扩大

#### Tab 3：误报治理

- 统计卡片行：总告警量、误报总量、总体误报率、待优化规则数
- 规则维度表格：
  | 列名 | 说明 |
  |------|------|
  | 规则名称 | 文本 |
  | 总告警量 | 数字 |
  | 误报数 | 数字 |
  | 误报率 | 百分比+趋势箭头 |
  | 趋势图 | 迷你折线图（按日/周切换） |
  | 操作 | 查看详情/调整参数/版本管理 |
- 标记误报弹窗：原因分类下拉（天气干扰/算法误判/参数不当/其他）+ 文字说明
- 参数调整对比：调整规则参数后记录前后快照（告警量+误报率），对比卡片展示
- 版本管理：
  - 每次规则修改生成新版本号（v1→v2→v3）
  - 版本列表：版本号、修改时间、修改人、变更概要
  - 任意两版差异对比（高亮变更字段）
  - 一键回退到历史版本

### 4.2 数据流向

```
地图区域管理 ──(区域数据)──→ 电子围栏预警 ──(规则)──→ 规则引擎
                                                    │
身份识别预警 ──(黑名单数据)──────────→ 规则引擎       │
                                                    │
行为预警     ──(行为规则)────────────→ 规则引擎       │
                                                    │
                                    命中目标 ────────→ 生成告警事件
                                                      │
                                                      ▼
                                             事件闭环管理
                                          ┌── 报警接收展示
                                          ├── 报警处置流程
                                          └── 误报治理
                                              │
                                         标记误报 ↓
                                      规则效果反馈 ──→ 预警规则管理（参数调优）
```

**关键数据关系**：
- 地图区域 ← 电子围栏规则（多对多，一个区域可绑多个规则）
- 电子围栏规则 → 告警事件（一对多，同一规则可触发多次告警）
- 黑名单 → 告警事件（一对多，同一黑名单目标可多次命中）
- 行为规则 → 告警事件（一对多，同一规则可触发多次告警）
- 预警规则 ← 规则版本（一对多，每次修改生成新版本）

## 五、边界情况处理

### 5.1 区域绘制边界

- 多边形至少需要3个顶点，少于3个时保存按钮禁用并提示
- 围栏区域必须闭合保存，小于等于0时校验提示
- 导入文件格式仅支持 GeoJSON 和 KML，格式错误时提示具体错误行
- 导入坐标超出地图范围时自动裁剪到可视范围

### 5.2 围栏规则边界

- 同一区域绑定的多条规则，优先级数值不可重复
- 生效日期结束时间必须大于开始时间
- 每日时间段不可重叠（同一规则内）
- 删除已被规则关联的地图区域时，弹窗提示"该区域已被 X 条规则关联，删除后规则将失效"并需二次确认
- 禁用规则后，该规则已触发的处置中事件不受影响

### 5.3 身份识别边界

- MMSI 在黑名单库内唯一，新增/导入时自动去重校验
- 批量导入时，Excel 中重复的 MMSI 以高亮提示，用户可选择覆盖/跳过/取消
- 删除黑名单目标后，该目标的历史命中记录保留
- 禁用黑名单目标后，该目标不再触发新告警，但已有告警事件不受影响

### 5.4 行为预警边界

- 航速上限必须大于下限
- 持续时间必须大于0
- 同一船型下同类型规则（如两条航速异常规则）可同时存在但需给出冲突提示
- 删除行为规则后，该规则触发的处置中事件保留，仅历史统计中标记为"规则已删除"

### 5.5 事件处置边界

- 已归档的事件不可修改和删除
- 标记为误报的事件不可再流转回处置中
- 同一事件不可重复派发至同一人
- 超时升级仅对"待核验"和"处置中"状态生效
- 批量操作（批量确认有效、批量标记误报）需二次确认
- 归档操作需填写归档说明

### 5.6 版本管理边界

- 回退操作本身不生成新版本，直接恢复到历史版本快照
- 同一规则连续两次修改生成两个独立版本
- 版本记录不可删除，仅随规则删除而清理

### 5.7 权限边界

- 复用系统现有角色权限体系（值班员/指挥员/设备操作员/运维管理员）
- 地图区域管理：指挥员可CRUD，值班员只读
- 预警规则管理：指挥员可CRUD，值班员只读
- 事件闭环管理：值班员可接收与处置，指挥员可派发与闭环归档
- 误报治理中的规则修改与版本回退：仅指挥员可操作
