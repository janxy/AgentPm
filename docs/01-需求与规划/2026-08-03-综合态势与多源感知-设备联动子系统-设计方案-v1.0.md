# 综合态势与多源感知-设备联动子系统设计方案

## 一、项目概述

### 1.1 系统背景

综合态势与多源感知系统是面向海上态势感知与管控的综合管理平台。系统接入雷达、AIS、北斗、光电视频、频谱侦测、气象水文等多源异构数据，通过统一时空基准进行融合处理，支撑目标管控、预警事件、设备联动、AI研判、数据分析等业务场景。

### 1.2 设备联动子系统定位

设备联动是预警事件的现场执行层——告警产生后，值班员、设备操作员通过光电视频确认现场、通过云台和取证工具采集证据、通过无人机空中核验、通过雷达回波辅助研判，形成"告警发现 → 现场核验 → 取证处置"的闭环。

### 1.3 核心价值

- 告警到现场的一键直达，缩短响应时间
- 光电、无人机、雷达多手段协同核验，提升研判准确率
- 截图、录像、喊话全流程留痕，支撑执法取证
- 雷达、光电、无人机、气象等设备统一状态管理，实时掌握可用资源

## 三、核心模块设计

### 3.1 设备总览

**路由**：`/device/overview`

**页面布局**：顶部统计卡片 + 左侧设备树（300px）+ 右侧 Leaflet 地图（flex: 1）

**顶部统计卡片**：
- 设备总数、在线数、离线数、故障数
- 卡片数字实时刷新，离线/故障卡在数量大于 0 时高亮提示

**左侧设备树**：
- 分组方式切换：按设备类型（雷达/光电/无人机/气象站）或按所属区域
- 树节点实时状态着色：在线绿色、离线灰色、故障红色
- 支持关键字搜索，命中节点自动展开定位
- 点击设备节点后，右侧地图自动定位并弹出设备信息窗
- 树节点操作：打开控制窗口、查看设备详情、刷新状态

**右侧地图**：
- 设备点位按状态分色显示，图标区分设备类型
- 点击点位弹出信息窗：设备名称、类型、所属区域、状态、经纬度、最近在线时间
- 信息窗提供“打开控制窗口”按钮，根据设备类型跳转对应联动页面并选中设备
- 底部设备状态图例：在线/离线/故障

**设备详情抽屉**：
- 设备档案：名称、编号、类型、型号、所属区域、安装位置、接入协议
- 运行参数：信号强度、最近心跳时间、今日在线时长
- 最近操作记录：云台控制、截图、录像、喊话、航线任务等操作留痕

### 3.2 光电联动

**路由**：`/device/optics`

**页面布局**：左侧设备列表（240px）+ 中间视频墙（flex: 1）+ 右侧控制面板（320px）

**左侧设备列表**：
- 展示在线/离线的光电设备，包含设备名称、安装位置、倍率、双光类型（可见光/红外/双光）
- 支持按状态筛选，点击选中设备后视频墙和云台面板联动切换
- 设备离线时列表项置灰，选中后视频窗显示“设备离线”

**中间视频墙**：
- 分屏布局切换：1/4/9/16 画面，单屏可全屏放大
- 每路视频用 Canvas 模拟实时画面，包含海浪/船只动态元素和轻微噪声，展示设备编号、倍率、UTC 时间水印
- 显示模式切换：可见光、红外、画中画、融合（双光设备可用）
- 双击视频窗可最大化，再次双击还原
- 网络波动模拟：弱网时自动切换子码流，画面清晰度降低并显示码流切换提示

**右侧云台控制面板**：
- 方位角/俯仰角实时数值显示，方位 0-360° 连续旋转，俯仰精确到 0.1°
- 八方向转动控制（上/下/左/右/左上/左下/右上/右下），按住连续转动，松开停止
- 变倍、聚焦控制：放大/缩小、聚焦近/远，步进微调，步长可配置（0.1° / 0.5° / 1°）
- 软限位展示：当前角度超出限位时按钮禁用并提示“已达软限位”
- 预置位管理：新增（记录当前方位/俯仰/倍率）、调用、重命名、删除，重名拦截
- 巡航配置：按顺序勾选预置位、设置停留时长，启动后模拟按序巡检，至少 2 个预置位才可启动

**取证操作栏**：
- 截图：Canvas 抓取当前画面，生成带时间水印的图片，存入取证记录
- 录像：开始/停止录像，生成录像片段列表，支持模拟下载
- 喊话：TTS 预设文案（驱离/警示/引导）一键广播，实时麦克风喊话模拟
- 取证记录面板：截图/录像/喊话统一留痕，展示时间、操作人、内容摘要，可展开查看

**事件上下文条**：
- 从预警事件“联动视频”进入时，顶部展示事件上下文：事件编号、目标名称/MMSI、触发规则、告警级别、处置状态
- 提供“返回事件”按钮，点击回到来源事件页
- 无事件上下文时隐藏该条，不影响独立使用

### 3.3 无人机联动

**路由**：`/device/uav`

**页面布局**：左侧无人机列表（240px）+ 右侧地图与航线规划（flex: 1）+ 底部任务控制条

**左侧无人机状态卡片**：
- 展示在线无人机列表，每架一张状态卡：当前位置、高度、速度、姿态（横滚/俯仰/航向）、剩余电量、距原点距离、预估续航
- 电量低于阈值时卡片标红，触发低电量返航提示
- 失联时卡片显示“信号丢失”，模拟自动返航

**右侧地图与航线规划**：
- Leaflet 地图拖拽设置航点，航点支持新增、删除、拖动调整顺序
- 起降点管理：预设起飞点/降落点，可在地图上新增编辑
- 逐段配置飞行高度和速度，地图上标注航段摘要
- 实时计算总航程、预估续航消耗，航程超过续航时给出“续航不足”警告并阻止下发
- 航线模板：保存当前航线为模板，模板列表一键复用

**底部任务控制条**：
- 基础飞行控制：起飞、返航、悬停
- 任务下发：选择航线模板或当前规划航线，确认后开始执行
- 任务执行进度条：当前航点、已飞航程、剩余航程、预计剩余时间
- 异常事件记录：低电量、信号丢失、偏离航线等自动记录
- 任务记录列表：任务开始/结束时间、途经点位、异常事件，支持查看详情

### 3.4 雷达监测

**路由**：`/device/radar`

**页面布局**：顶部雷达站信息栏 + 左侧 Canvas PPI 回波区（flex: 1）+ 右侧目标列表（320px）

**顶部雷达站信息栏**：
- 雷达站选择、显示模式切换（A 式/R 式）
- 运行参数：信号强度、天线转速、设备温度、工作状态
- 参数控制：量程切换、增益调节、回波色标方案切换

**左侧 PPI 回波区**：
- Canvas 绘制 PPI 回波：距离环、方位刻度、扫描波束，扫描线按天线转速旋转
- 回波点按强度分级着色，弱回波自动增益补偿模拟
- 点击目标列表中的目标，PPI 上对应回波点高亮闪烁
- 截图按钮抓取当前 PPI 画面，生成带时间水印的取证图片，可关联事件记录

**右侧目标列表**：
- 列字段：目标编号、距离、方位、速度、目标等级
- 支持按距离/速度/等级排序，按距离范围、方位范围筛选
- 点击列表行在 PPI 区高亮对应回波点，再次点击取消高亮
- 目标等级用颜色标签区分：高关注/一般/微弱

### 3.5 预警事件联动入口

**位置**：`/alert/event` 报警接收展示、报警处置流程表格

**交互**：
- 每行事件操作区增加“联动视频”按钮
- 点击后路由跳转 `/device/optics?deviceId=xxx&eventId=xxx&targetId=xxx`
- 光电联动页读取查询参数，自动选中对应光电设备，顶部展示事件上下文条
- 事件未关联可用光电设备时，跳转后提示“该事件未关联在线光电设备”，仍可手动选择其他设备
- 联动过程中的截图、录像、喊话记录关联事件 ID，供后续事件详情查询

**关闭联动**：
- 光电联动页点击“返回事件”，回到来源事件页并保持筛选与分页状态
- 直接切换其他设备联动菜单时清除事件上下文，避免跨页误关联

### 4.2 数据流向

```
预警事件（联动视频） ──(eventId/targetId/deviceId)──→ 光电联动页
                                                          │
设备总览（设备树/地图点位） ──(选中设备)──→ Pinia deviceStore
                                                          │
                                                   控制操作/取证
                                                          │
                                              ┌───────────┴───────────┐
                                              ▼                       ▼
                                         Mock 接口更新状态        取证/喊话记录
                                         （云台/视频/任务/雷达）      │
                                              │                   关联 eventId
```

**关键数据关系**：
- 设备 1:N 预置位、取证记录、喊话记录
- 光电设备 1:N 巡航计划；巡航计划 N:M 预置位
- 无人机 1:N 任务；航线模板 1:N 航点；任务可引用模板
- 雷达站 1:N 雷达目标
- 预警事件 1:N 取证记录（跨模块关联，用于材料归档）

## 五、边界情况处理

### 5.1 设备状态边界

- 设备离线/故障时，对应控制按钮禁用，视频窗显示“设备离线”，地图点位变灰/变红
- 设备离线后已打开的视频窗保留最后画面并叠加离线遮罩，避免画面闪烁
- 设备状态由 Mock 定时心跳模拟，可手动刷新；故障设备点击“重启”后进入恢复倒计时

### 5.2 光电联动边界

- 方位角超出软限位时停止转动并提示“已达软限位”
- 预置位名称在同一设备内唯一，重名时拦截
- 巡航计划少于 2 个预置位时不可启动，提示补充预置位
- 双光设备的画中画/融合模式在单光设备上隐藏
- 截图/录像在设备离线时禁用
- 弱网模拟下切换子码流，主码流恢复后自动切换回来

### 5.3 无人机联动边界

- 电量低于配置阈值时触发自动返航提示，任务自动暂停
- 信号丢失超过阈值时模拟自动返航，恢复后提示“信号已恢复”
- 航点少于 2 个时不可下发任务
- 航程超过预估续航时阻止下发并提示“续航不足”
- 任务执行中禁止重复下发，先返回“任务正在执行中”
- 返航/悬停操作需任务处于执行状态，否则提示当前状态不可操作

### 5.4 雷达监测边界

- 无目标时 PPI 仅保留扫描线、距离环和方位刻度
- 雷达离线时 PPI 冻结并显示离线遮罩，目标列表清空
- 增益/量程调整后回波显示实时刷新，色标方案切换不改变目标数据
- 截图在雷达离线时禁用

### 5.5 联动入口边界

- 事件未关联在线光电设备时，跳转后提示并允许手动选择设备
- 事件上下文仅在同一次联动会话内有效，切换菜单或刷新后自动清除
- “返回事件”通过记录来源路由实现，避免多层跳转后丢失位置
- 取证记录关联事件 ID，事件归档后记录仍保留且不可修改

### 5.6 权限边界

- 复用现有角色体系（值班员/指挥员/设备操作员/运维管理员）
- 设备操作员：可查看设备总览、控制设备、取证、喊话、下发无人机任务
- 值班员：可查看设备状态与视频，不可控制设备
- 指挥员：全部可操作，并可发起联动查看
- 运维管理员：可查看设备档案与运行状态，不可控制业务操作
- 按钮级权限控制：无权限按钮直接隐藏，不展示不可点击状态

### 5.7 空态与演示边界

- 所有列表、视频墙、地图点位、目标列表提供空态文案
- Mock 数据支持“重置演示数据”操作，一键恢复初始数据
- Canvas 模拟定时器在页面销毁时统一清理，避免内存泄漏
- 分屏切换时保持当前选中设备画面，不因布局变化中断操作
