# 综合态势与多源感知-预警区域围栏父子级-设计方案

## 一、项目概述

将预警事件中的“地图区域管理”与“电子围栏预警”明确为父子级关系：区域是父级，电子围栏是子级。电子围栏创建时必须选择所属区域，区域列表展示面积与围栏数量；绘制围栏时以所属区域边界作为参照，不限制围栏必须完全落在区域内。

## 二、功能范围

1. 地图区域管理：去除有效期字段，新增面积、电子围栏数量展示。
2. 电子围栏预警：新增所属区域字段，列表展示所属区域，绘制时显示区域边界参照。
3. 区域删除保护：区域下存在电子围栏时禁止删除。

## 三、核心模块设计

### 地图区域管理

- 新增/编辑表单字段：区域名称、区域类型、负责人、备注、区域范围。
- 列表字段：区域名称、类型、面积、电子围栏数量、状态、操作。
- 面积由区域几何数据计算，围栏数量按电子围栏的 `areaId` 统计。
- 示例数据补充“厦门海域”区域。

### 电子围栏预警

- 新增/编辑表单增加“所属区域”必填项，选择区域后保存 `areaId`。
- 列表增加“所属区域”列。
- 绘制围栏时，地图以虚线样式绘制所属区域边界作为参照，围栏可自由绘制，不做越界校验。

## 四、数据结构与流向

`area`（区域）1:N `fenceRule`（电子围栏）

- 区域记录：`id`、`name`、`type`、`geoData`、`managerName`、`remark`、`status`。
- 围栏记录：`id`、`name`、`areaId`、`geoData`、生效时间配置、适用目标配置、告警配置。
- 区域列表返回 `areaText`（面积文本）与 `fenceCount`（围栏数量）。
- 围栏列表返回 `areaName`（所属区域名称）。

## 五、边界情况处理

1. 删除区域时存在子围栏：提示“请先删除该区域下的电子围栏”，禁止删除。
2. 新建围栏未选择所属区域：不允许打开绘制弹窗，并提示先选择所属区域。
3. 切换所属区域后已绘制的围栏范围清除，避免跨区域误配。
4. 围栏绘制不校验是否超出区域边界，仅提供视觉参照。
