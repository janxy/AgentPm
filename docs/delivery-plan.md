## 功能详情

### 第1层：系统基础（无依赖，优先实现）

#### F01 ─ 预警事件路由与菜单框架

**路由注册**：
- 创建 `src/router/modules/alert.ts`，定义预警事件路由树
- 一级菜单"预警事件"，icon 使用 `WarningFilled`
- 二级菜单：地图区域管理、预警规则管理、事件闭环管理


**验收标准**：

- Mock 模式下路由正常工作

### 第2层：核心依赖基础（F02）

#### F02 ─ 地图区域管理

**路由**：`/alert/area`

**页面布局**：左侧区域列表（280px）+ 右侧 Leaflet 地图容器（flex:1）

**功能清单**（SRS 3.5.1）：
- 筛选：区域名称（模糊搜索）、区域类型（下拉）、状态（下拉）
- 列表：区域名称、类型标签、有效期、状态、操作（编辑/删除/绑定规则）
- 新增/编辑：弹窗表单（名称/类型/有效期/负责人/备注），地图绘制（绘点/绘线/绘面/导入GeoJSON-KML）
- 删除：确认弹窗 + 关联规则检测
- 绑定预警规则：勾选已有规则列表
- 审批：编辑后→待审批→通过/驳回（基础版本先实现状态流转）

**地图能力**：
- Leaflet 轻量组件，卫星/矢量底图切换
- 绘制工具条：绘点、绘线、绘面（多边形）
- 已绘制区域半透明填充 + 边框高亮
- 点击区域弹出信息窗，支持拖拽编辑顶点

**验收标准**：
- 左侧列表正确展示区域数据（Mock）
- 右侧地图正常渲染，可用绘制工具画区域
- 新增区域后列表刷新，地图同步显示
- 编辑提交后状态变更为待审批

### 第3层：预警规则管理（F03/F04/F05）

**路由**：`/alert/rule`，默认展示电子围栏预警 Tab

#### F03 ─ 电子围栏预警

**路由**：`/alert/rule/fence`（Tab 默认激活项）

**功能清单**（SRS 3.5.2.1）：
- 筛选：规则名称、围栏类型、状态
- 列表：规则名称、围栏类型标签、关联区域、生效时段摘要、适用目标摘要、优先级（拖拽排序）、告警级别标签、状态开关、操作（编辑/删除/查看命中历史）
- 新增：分步配置——规则名称→围栏类型（圆形/多边形/航线廊道）→几何参数→关联区域→生效日期范围→每日时间段→按星期重复→适用船型→吨位范围→目标来源→优先级→告警级别
- 编辑：自动填入 + 状态独立管理
- 删除：确认弹窗
- 优先级拖拽排序

**验收标准**：
- Tab 模式切换正常
- 围栏规则列表正确展示
- 新增规则时围栏类型切换后参数区域动态变化
- 关联区域下拉可选择 F02 中已创建的区域

#### F04 ─ 身份识别预警

**路由**：`/alert/rule/blacklist`

**功能清单**（SRS 3.5.2.2）：
- 筛选：目标名称/MMSI、等级、状态
- 列表：目标名称、MMSI、呼号、目标编号、等级标签、加入原因、命中次数、加入时间、状态开关、操作（编辑/删除/查看命中历史）
- 新增：填写目标名称/MMSI/呼号/目标编号/等级/加入原因
- 编辑：MMSI 不可修改
- 批量导入：下载模板→填写上传→MMSI 去重校验→预览确认→入库
- 查看命中历史：统计卡片（总命中次数、最近命中时间）+ 命中记录表

**验收标准**：
- 黑名单列表正确展示
- 新增时 MMSI 唯一性校验
- 批量导入流程（模板下载→上传→预览→确认）
- 三级等级差异化标签颜色

#### F05 ─ 行为预警

**路由**：`/alert/rule/behavior`

**功能清单**（SRS 3.5.2.3）：
- 船型筛选：多选渔船/货船/客船/快艇/橡皮艇/三无船
- 四种行为类型各一张规则卡片：
  - 航速异常：航速上限/下限、持续时长、告警级别、启用开关
  - 航向异常：航向偏差角度、持续时长、告警级别、启用开关
  - 异常停留：停留时长阈值、告警级别、启用开关
  - 轨迹断线：断线判定时长、自动研判分类（多选）、告警级别、启用开关

**验收标准**：
- 船型多选后下方展示对应规则卡片
- 每张卡片独立编辑保存
- 保存时校验（上限>下限、持续时长>0）
- 同船型多规则保存时给出冲突提示

### 第4层：事件闭环管理（F06）

**路由**：`/alert/event`

**页面布局**：顶部统计卡片 + 三个 Tab（告警接收、事件处置、误报治理）

#### F06 ─ 事件闭环管理

**功能清单**（SRS 3.5.3）：

**统计卡片**：待核验数、处置中数、今日闭环数、超时未处置数（点击筛选）

**Tab 1：告警接收展示**
- 筛选：告警等级、规则名称、目标名称/MMSI、状态、发生时间
- 列表：告警等级标签、规则名称、目标信息、发生时间、位置（点击定位）、状态、操作（查看详情/确认有效/标记误报/联动查看）
- 推送配置入口：告警级别→推送渠道、推送角色、超时阈值

**Tab 2：事件处置**
- 状态流转：待核验→确认有效（处置中）→派发处置→闭环→归档
- 或：待核验→标记误报（进入误报治理）
- 每步操作填写说明，自动记录时间线
- 派发至指定值班人员
- 操作时间线展开查看

**Tab 3：误报治理**（独立页面，F08 需求，此处先放骨架）

**验收标准**：
- 三个 Tab 正确切换
- 告警列表根据 Mock 数据正确渲染
- 状态流转按钮按状态正确显示/隐藏
- 操作时间线可展开查看
- 统计卡片数字正确

### 第5层：高级功能（F07-F10）

#### F07 ─ 区域变更审批

**位置**：F02 地图区域管理页面内嵌

**功能**：
- 编辑区域后状态变更为"待审批"
- 审批列表展示变更内容对比（修改前 vs 修改后，差异高亮）
- 指挥员可选择"通过"（变更为生效）或"驳回"（恢复修改前状态）

#### F08 ─ 误报治理与规则优化

**位置**：F06 事件闭环管理 → Tab 3

**功能**：
- 统计卡片：总告警量、误报总量、误报率、待优化规则数
- 规则维度表格：规则名称、类型、告警量、误报数、误报率（趋势箭头）、迷你趋势图
- 标记误报：原因分类（天气干扰/算法误判/参数不当/其他）+ 说明
- 参数调整对比：参数快照前后对比 + 效果对比

#### F09 ─ 规则版本管理

**位置**：各预警规则页面内嵌（F03/F04/F05）

**功能**：
- 版本列表：版本号（v1→v2→v3）、修改时间、操作人、变更概要
- 任意两版差异对比（变更字段高亮）
- 一键回退到历史版本（不生成新版本号）

#### F10 ─ 多渠道分级推送配置

**位置**：F06 事件闭环管理 → 告警接收 Tab → 右上角配置入口

**功能**：
- 告警级别→推送渠道映射（弹窗/APP推送/短信/邮件）
- 告警级别→推送角色映射（值班员/指挥员/设备操作员）
- 待核验超时阈值 + 处置中超时阈值
